# 13 — Fonksiyonel olmayan gereksinimler

Bu maddeler ilk fazdan itibaren dikkate alınacak; güvenlik ve veri bütünlüğü sona ertelenmeyecektir.

| ID | Gereksinim |
|---|---|
| NFR-001 | Web sitesi telefon, tablet ve bilgisayarlarda düzgün çalışmalı. |
| NFR-002 | Arayüz sade ve kolay kullanılabilir olmalı. |
| NFR-003 | Sık kullanılan işlemler az sayıda tıklamayla yapılabilmeli. |
| NFR-004 | Sayfalar hızlı açılmalı ve performans ölçülmeli. |
| NFR-005 | Kullanıcı şifreleri güvenli hash mekanizmalarıyla saklanmalı. |
| NFR-006 | HTTPS kullanılmalı. |
| NFR-007 | Öğretmenler birbirlerinin verilerine erişememeli. |
| NFR-008 | Önemli veritabanı işlemlerinde veri bütünlüğü korunmalı. |
| NFR-009 | Form verileri sunucu tarafında doğrulanmalı. |
| NFR-010 | Hata mesajları anlaşılır olmalı ve hassas teknik ayrıntılar göstermemeli. |
| NFR-011 | Veritabanı yedekleme ve kurtarma planı bulunmalı. |
| NFR-012 | Kritik değişiklikler kayıt altına alınmalı. |
| NFR-013 | Uygulamanın mimarisi ileride mobil uygulama eklenmesine uygun olmalı. |
| NFR-014 | Kişisel veriler için KVKK gereksinimleri değerlendirilmeli ve uygun saklama/silme süreçleri uygulanmalı. |
| NFR-015 | Kodlar modüler, test edilebilir ve bakım yapılabilir olmalı. |

**Ölçüm notu:** Performans ve erişilebilirlik için sayısal kabul eşikleri, hedef kullanıcı/cihazlarla yapılan testlerden sonra belirlenecek; henüz kararlaştırılmadı.
